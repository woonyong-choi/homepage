# 개인 랜딩 페이지

홈은 소개와 출연 영상, 기술, 동료 인터뷰, 연락 구간을 조립한다. 내용과 순서는 `src/home.config.yaml`에 있고 설정 계약은 [홈 설정 가이드](home-config.md)에 있다.

소개 영상은 사용자가 선택한 인터뷰 한 편이다. 포스터에서 재생하면 화면 안에서 펼쳐지고 처음부터 재생한다. 기술은 오른쪽, 인터뷰의 두 행은 반대 방향으로 흐른다. 마우스를 올리거나 떼어도 흐름은 유지한다. 키보드 초점·가로 휠·터치 조작·움직임 줄이기에서는 멈추고 숨은 화면에서는 작업을 중단한다. 이 자동 흐름은 Things의 수동 후기 탐색과 구분되는 개인 사이트의 요구사항이다.

프로젝트 구간은 실제 자료를 넣기 전까지 설정에서 꺼 둔다. 비공개 인터뷰 원본은 공개 자산에 넣지 않는다. 명시적으로 승인한 요약만 설정에 넣고 미리보기의 예시 카드는 운영 빌드에서 제외한다.

구독은 외부 서비스의 HTTPS 폼 주소가 설정되기 전까지 비활성이다. 사이트가 구독자를 직접 저장하지 않는다.

## 구성 요소

Hero, SectionIntro, Section, ProjectShowcase, FlowRail, LogoItem, QuoteCard, EmailForm, SiteHeader, SiteFooter는 공통 디자인 패키지에서 가져온다. 홈페이지는 콘텐츠·경로·공개 조건을 넘긴다. 같은 모양을 지역 CSS나 인라인 스타일로 다시 만들지 않는다.

## 확인

홈을 넓은 화면과 작은 화면에서 확인한다. 영상의 포스터·재생·접힘, 흐름의 정지와 재개, 링크의 초점, 구독의 비활성 상태를 대조한다. 작업용 Chrome 탭은 확인 후 닫는다.
