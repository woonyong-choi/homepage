## 요약

홈은 소개와 영상, 기술, 동료평가, 연락 구간을 공통 디자인 구성 요소로 조립한다.

## 해결하는 문제

사이트 방문자는 소개와 작업 분야, 동료평가를 한 페이지에서 읽어야 한다. 내용은 승인 원고로 관리하고 같은 구간 머리와 탐색 동작을 공유한다.

## 사용 예

### 사용 장면

소개에서 영상 보기 링크를 누르면 영상이 펼쳐진다. 기술과 동료평가의 흐르는 목록에 키보드 초점을 두면 자동 이동이 멈추고 직접 읽을 수 있다.

## 작동 방식

### 입력과 구성

홈은 소개와 출연 영상, 기술, 동료 인터뷰, 연락 구간을 조립한다. 구간 순서와 홈 소개는 `content/home.md`, 기술은 `content/pages/tech.md`, 동료평가는 `content/interviews/index.md`에 있고 설정 계약은 [홈 원고 가이드](home-content.md)에 있다.

소개 영상은 사용자가 선택한 인터뷰 한 편이다. 포스터에서 재생하면 화면 안에서 펼쳐지고 처음부터 재생한다. 기술 로고는 `/search/?tag=python`처럼 Blog의 태그 목록으로 연결한다. 공개 상단 탐색은 Search와 Blog다. Search는 전체 글의 목록·검색·태그 탐색이며 Blog는 같은 글의 최근 날짜순 본문 피드다. 기술은 오른쪽, 인터뷰의 두 행은 반대 방향으로 흐른다. 마우스를 올리거나 떼어도 흐름은 유지한다. 키보드 초점·가로 휠·터치 조작·움직임 줄이기에서는 멈추고 숨은 화면에서는 작업을 중단한다. 이 자동 흐름은 Things의 수동 후기 탐색과 구분되는 개인 사이트의 요구사항이다.

프로젝트 구간은 실제 자료를 넣기 전까지 설정에서 꺼 둔다. 비공개 인터뷰 원본은 공개 자산에 넣지 않는다. 명시적으로 승인한 요약만 설정에 넣고 미리보기의 예시 카드는 운영 빌드에서 제외한다.

연락 구간은 원고의 모드에 따라 구독 폼 또는 이메일 직접 문의 링크를 제공한다. 구독 전송 주소가 없으면 폼을 비활성화하고 이메일 주소를 받지 않는다. 설정과 전송 조건은 [홈 원고 가이드](home-content.md)를 따른다.

### 구성 요소

Hero, SectionIntro, Section, ProjectShowcase, FlowRail, LogoItem, QuoteCard, SiteHeader, SiteFooter는 공통 디자인 패키지에서 가져온다. 홈페이지는 콘텐츠·경로·공개 조건을 넘긴다. 같은 모양을 지역 CSS나 인라인 스타일로 다시 만들지 않는다.

밝은 테마의 홈 헤더와 소개·동료평가 영역은 흰색이다. 구독·푸터는 기존 회색 구획을 유지한다. 제목 아이콘은 공통 머리의 글자 기준선에 맞추며, 영상 링크는 평소·호버·키보드 초점 상태에서 밑줄을 표시하지 않는다.

### 확인

홈을 넓은 화면과 작은 화면에서 확인한다. 영상의 포스터·재생·접힘, 흐름의 정지와 재개, 링크의 초점, 메일 링크의 주소를 대조한다. 작업용 Chrome 탭은 확인 후 닫는다.

공통 디자인 수정은 ThinkFlow와 홈페이지가 같은 배포본을 소비한 뒤 확인한다. 렌더러 의존성은 `github:woonyong-choi/thinkflow#<전체 커밋>`으로 고정한다. 작업본의 검수용 인터뷰 입력과 실행 중인 미리보기의 원본 경로를 확인하고, 최종 확인은 주 작업본의 미리보기에서 한다.
