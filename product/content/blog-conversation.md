## Siri AI (Beta)

기록을 시작하는 방법은 상황마다 다릅니다. 손으로 입력할 수도 있고, 떠오른 생각을 말로 남길 수도 있습니다. 이 글은 음성 입력에서 작업 목록으로 이어지는 흐름을 살펴보기 위한 화면 예시입니다. 실제 서비스의 제공 여부와는 관계없는 더미 본문입니다.

한 번에 모든 내용을 정리하지 않아도 됩니다. 먼저 간단한 작업을 기록하고 필요한 정보를 조금씩 덧붙여 보세요. 아래에서는 요청을 구체화하고, 대화를 이어가고, 결과를 다시 확인하는 순서로 살펴봅니다.

### Speak more freely

말로 떠올린 생각에는 작업의 제목뿐 아니라 시기나 배경이 함께 들어갈 수 있습니다. 짧은 요청을 하나의 목록 항목으로 정리하는 모습을 확인해 보세요. 화면 안에서 어떤 정보가 강조되고 어떤 내용이 보조 정보로 남는지도 비교할 수 있습니다.

자연스럽게 이야기한 내용을 바로 확인할 수 있으면 입력의 흐름을 유지하기 쉽습니다. 아래 이미지는 음성 요청과 정리된 작업이 나란히 나타나는 예시입니다.

```ui:figure
{
  "src": "os27-speakfreely-io70.jpg",
  "alt": "말로 요청한 내용이 작업 항목으로 정리되는 화면",
  "caption": "말로 요청한 내용이 작업 항목으로 정리되는 화면",
  "wide": true
}
```

입력 결과를 확인한 뒤 필요한 부분을 수정합니다. 짧은 제목부터 시작해 날짜나 메모를 더하며 원하는 작업으로 구체화할 수 있습니다. 대화와 목록 사이에서 정보를 다시 확인하는 과정도 중요합니다.

사용 흐름을 검토할 때 다음 항목을 함께 확인하세요.

- 새 작업이 들어갈 목록이 분명하게 보이는지 확인합니다.
- 입력한 날짜와 화면에 표시된 일정이 같은 맥락으로 이어지는지 살펴봅니다.
- 세부 정보를 수정한 뒤에도 기존 내용이 자연스럽게 유지되는지 확인합니다.

말하기 어려운 환경에서는 키보드 입력으로 같은 내용을 정리할 수 있습니다. `⌘ Cmd` + `Space` 같은 키 표시도 본문과 함께 표현할 수 있습니다.

### Keep the conversation going

하나의 요청으로 모든 정보를 정리할 필요는 없습니다. 대화를 이어가며 표현을 고치거나 새로운 내용을 덧붙이는 흐름을 살펴보세요. 화면의 번호를 선택하면 같은 자리에서 단계별 이미지가 전환됩니다.

## Spotlight

이미 기록한 정보를 다시 찾는 과정도 중요합니다. 제목과 관련된 단어를 입력하고 여러 결과 중에서 원하는 작업으로 돌아가는 화면을 살펴봅니다.

- 현재 작업과 관련된 기록이 어떤 순서로 나타나는지 확인합니다.
- 검색 결과에서 필요한 맥락을 이해하고 원래 목록으로 이동하는 흐름을 비교합니다.

```ui:figure
{
  "src": "os27-spotlight-io70.jpg",
  "alt": "검색 결과에서 작업과 프로젝트를 확인하는 화면",
  "caption": "검색 결과에서 작업과 프로젝트를 확인하는 화면",
  "wide": true
}
```

검색 결과는 입력한 표현과 기록한 내용에 따라 달라질 수 있습니다. 이 예시에서는 결과의 제목과 보조 설명, 항목 사이의 간격을 확인할 수 있습니다.

필요한 정보를 찾은 뒤에는 다시 본문으로 돌아와 읽던 흐름을 이어갑니다. 긴 문서에서도 현재 위치를 놓치지 않도록 구성합니다.

## Snoozing Notifications

알림을 확인했지만 바로 처리하기 어려운 상황도 있습니다. 다음에 확인할 시간을 선택하는 화면을 통해 여러 선택지가 어떻게 구분되는지 살펴보세요.

- 자주 사용하는 선택지를 가까운 위치에 보여 줍니다.
- 선택지마다 의미가 다른 시간을 분명하게 표시합니다.
- 기기가 달라져도 같은 내용을 이해할 수 있는 순서를 유지합니다.

```ui:figure
{
  "src": "os27-snooze-io70.jpg",
  "alt": "알림에서 다음 확인 시간을 선택하는 화면",
  "caption": "알림에서 다음 확인 시간을 선택하는 화면",
  "wide": true
}
```

---

같은 정보를 서로 다른 화면에서 보여 줄 때에는 **위계와 일관성**을 함께 확인합니다. 작은 화면에서는 핵심 내용이 먼저 보이고, 넓은 화면에서는 전체 맥락을 쉽게 살펴볼 수 있어야 합니다.

이 예시의 이미지와 슬라이드를 비교하며 입력에서 정리, 검색과 확인으로 이어지는 흐름을 살펴보세요.

각 기기의 화면은 [Mac](/things/mac/), [iPad](/things/ipad/), [iPhone](/things/iphone/), [Vision Pro](/things/vision/) 예시 페이지에서 이어 볼 수 있습니다.
