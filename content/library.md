## Overview

Explore reusable Supabase components and examples.

### Example

Reusable examples still need a client configured for the application’s own project.

```js
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(projectUrl, publishableKey)
```

## Explore

Browse components by use case, then inspect each example and its dependencies before adding it to a project.

## Apply

Connect it with your project credentials and test its data permissions in the application.
