## Create a project

Create a Supabase project, then use its project URL and publishable key in your application. Keep secret keys on the server.

### Example

Install the JavaScript client before connecting a web application.

```sh
npm install @supabase/supabase-js
```

## Connect your application

Choose a framework from the landing page and follow its quickstart. The guide should end with a working read or write against your project.
