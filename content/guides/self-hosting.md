## Overview

Self-hosting requires running and operating the services that make up the Supabase platform.

### Example

Check the state of services in a self-hosted Compose deployment.

```sh
docker compose ps
```

## Plan operations

Review deployment, secrets, backups, monitoring, upgrades, and service dependencies before choosing this path.
