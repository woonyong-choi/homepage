## Overview

Organizations group projects and provide a place to manage team access and project ownership.

### Example

List organizations accessible to the signed-in CLI user before selecting a project.

```sh
npx supabase orgs list
```

## Access review

Grant only the roles collaborators need and review access when a project moves between teams or stages.
