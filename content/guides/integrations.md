## Overview

Connect partner tools to Supabase.

### Example

Many integrations require a project URL and publishable key; keep privileged credentials server-side.

```dotenv
SUPABASE_URL=https://PROJECT.supabase.co
SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

## Explore

Choose an integration, review the data and permissions it needs, and configure it for the correct project.

## Apply

Run a small end-to-end check and inspect logs or events before using it in production.
