## Overview

Connect AI development tools to a Supabase project.

### Example

Add the current Supabase agent skills to a project before using an AI coding tool.

```sh
npx skills add supabase/agent-skills
```

## Explore

Choose whether your workflow needs contextual instructions, an MCP connection, or both. Keep tool permissions scoped to the project and task.

## Apply

Verify the tool can inspect only the intended project and review changes before applying them.
