## Start with the symptom

Record the exact error, affected environment, and the last relevant change. Check project status and logs before changing configuration.

### Example

For a local stack, check running services before investigating a failed request.

```sh
npx supabase status
```

## Narrow the cause

Reproduce the issue with the smallest request or workflow, then compare credentials, policies, network behavior, and deployed versions.
