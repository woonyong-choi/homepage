## Overview

Edge Functions run server-side code for work that belongs outside the browser, such as private integrations or request processing.

### Example

Create an Edge Function locally, then implement and test its handler before deployment.

```sh
npx supabase functions new hello-world
```

## Development flow

Create a function, test it locally, and deploy it to the project. Keep secrets in the server-side environment and validate incoming requests.
