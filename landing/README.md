# 개인 랜딩 시안

Things의 중앙 정렬·짧은 소개·넓은 여백을 참고한 정적 입구다. 기존 base의 라이트 모드 토큰을 사용한다. 프로젝트·블로그·위키의 상세 목록은 기존 페이지로 연결한다.

자동 이동, 카드 복제, 자동 영상 미리보기와 정지 조작은 제거했다. 영상 파일은 소개 영상 보기 버튼을 누른 뒤에만 연결한다. 닫거나 비활성 탭으로 이동하면 재생을 멈춘다. 실패하면 플레이어 조작 또는 재시도 안내를 제공한다.

동료 평가 두 개는 레이아웃 검토용 예시다. 영상은 기존 테마 색으로 만든 6초 추상 모션 샘플이다. 실제 평가나 출연 영상을 사용하지 않았다. PC 화면 비율을 검토하는 viewport를 유지한다.

스타일 정본은 design-tokens의 base다. 공개 미리보기에는 명시한 정적 파일만 내보낸다. 기존 문서형 페이지와 이전 움직이는 시안은 Git 이력에 보존한다.
